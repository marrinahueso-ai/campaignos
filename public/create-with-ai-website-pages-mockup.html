Level 1 vs Level 2

Same Create with AI → Website pages library. Different editors for the same MTK export promise.

Level 1 · Templates

Feels like today’s Homepage Composer

  • Fixed steps per page type
  • Cannot invent new layouts without a new template
  • Consistent MTK look
  • Ship Resources / Volunteer / Sponsorship as siblings
  • Recommended first
STEPS: Intro → Categories → Preview → Export
Sections locked · fill fields only

Level 2 · Blocks

Component palette + ordered canvas

  • Add / remove / reorder blocks
  • Mix Hero, Opps, Partner tiers, Links…
  • Templates become starter stacks
  • More engineering + QA
  • Evolve after 3–4 templates
CANVAS: ≡ Hero ≡ How-to ≡ Opps ≡ CTA
