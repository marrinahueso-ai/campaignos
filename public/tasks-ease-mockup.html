What this mockup is solving

Today’s Tasks page stacks summary KPI tiles, Main Table / My Tasks / Board tabs, and dense toolbar chrome. Ease keeps the same event-linked tasks with quieter structure.

  • Team vs Mine — managers see the whole org; individuals only see tasks assigned to them (still grouped by event).
  • List — each event in its own box with a calendar-style color stripe + color picker; rows deep-link to that event’s Tasks tab.
  • Status / Focus / Custom boards — column color pickers (top stripe); cards keep the event color stripe.
  • Quieter chrome — Team/Mine + views on one row; pulse as text links; lighter event Show chips.
