How it works

In product, each month stores its own homepage cards draft. Header and footer stay “design once.” Switching months loads that month’s snapshot — empty until you save or copy. This page is the ease mock for reference; use Homepage Composer for real persistence.

  1. Pick Working on month (August → September).
  2. Save this month stores that month’s cards under August.
  3. September starts empty — or use Copy from… to start from July/August.
