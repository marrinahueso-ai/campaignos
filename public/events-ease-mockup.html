Why this layout

Today’s Events page leads with five equal KPI cards, a dense filter bar, then a small upcoming carousel that mostly repeats the list underneath.

  • Upcoming first — a big “coming up” plane so you can see the season ahead, not just a thin strip.
  • Soft pills for Needs setup / Ready / Follow-up / Done — same ease language as Approvals & Volunteers.
  • Create with AI in the header + suite strip — creative work starts from the studio you already love; Events stays the catalog.
  • Month at a glance — soft calendar grid on Events (not a trip to Full calendar).
  • All → Month/Year filter — slice the catalog by school-year month without the old dense toolbar.
  • Full calendar → still available for the heavyweight month view when you need it.
