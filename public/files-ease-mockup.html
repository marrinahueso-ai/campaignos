What this mockup is solving

Today’s Files page leans on a dense carousel + filter toolbar + flat table. Ease keeps the same event-linked library with quieter structure.

  • Organized by event — each event in its own striped box; deep link to /events/{id}?tab=files.
  • Search — file name or event title, instant.
  • Rename — inline on the row (saves on Enter / blur).
  • Sort — Newest · Name · Size · Type as quiet text controls.
  • Same files — org /files and the event Files tab share one library.
